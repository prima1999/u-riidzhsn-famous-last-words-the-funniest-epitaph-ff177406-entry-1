Entry for make.fun's [Famous Last Words: The Funniest Epitaph](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406) bounty.

The program writes one tombstone epitaph — a single line of famous last words, at most 150 characters — to `/output/entry.txt`:

> After 31 years in accounting, I asked for my ashes to be mixed into the office coffee machine, so for once everyone here will wake up because of me.

## Run

```sh
node main.ts
```

`main.ts` uses only the Node standard library and writes the epitaph to `$OUTPUT_DIR/entry.txt` (default `/output`).
